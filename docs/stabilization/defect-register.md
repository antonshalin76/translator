## Stage order

1. A — restore trustworthy deterministic gates, exact collection manifests, schema/publication checks, and remediate dependency advisories.
2. B — fail-closed safety, atomic control/session ownership, lifecycle, and cloud correlation.
3. C — one typed mode/deadline/flow policy and real mode-specific endpointing.
4. D — accuracy/oracles, readiness, debug lifecycle, hotplug, and observability.
5. E — portable atomic installer, authenticated health, rollback, packaging, and release workflow.
6. F — frozen diverse corpus; paired baseline/candidate quality, latency, soak, round-trip, native UI, real-app, and claimed-provider evidence; release only the frozen passing SHA.
