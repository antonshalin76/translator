# GitHub Description

Local Linux desktop app for full-duplex Russian/English speech translation in live calls, with PipeWire audio routing, a Rust daemon, Python speech providers, and a Tauri control UI.

## Short Alternatives

- Full-duplex Ru/En call translator for Linux desktops.
- Local-first speech translation for Zoom, Google Meet, Telegram Desktop, and similar calls.
- PipeWire-based desktop speech translator with local and opt-in cloud providers.
